# Prompt 4c: Copilot Access Issue

## Immediate Service Desk Action

1. Confirm the reported Copilot access issue has been logged as a security/data-governance investigation and record the incident/case reference: **to confirm**.
2. Preserve the original report without attempting to reproduce the result or change the user's permissions. Record the affected user's identity, device name, approximate date/time, the matter identifier, and the exact Copilot prompt/response only through the approved incident evidence process; any missing detail is **to confirm**.
3. Confirm the case has been routed to the responsible Security, Data Governance, Microsoft 365/Copilot, and DMS permission owners: **to confirm**.
4. Tell the reporting user that the matter is under investigation and that Service Desk has not confirmed a root cause or resolution. Do not state that access was appropriate, inappropriate, removed, or contained until the investigation owner confirms it.
5. Keep the ticket open, link any security/data-governance case reference, and update the user only with approved investigation communications.

Service Desk should not apply a permission change, remove group membership, alter DMS or SharePoint access, delete Copilot history, or attempt a technical fix. The effective entitlement path, whether it was intended, the relevant content source, and the appropriate containment decision are all **to confirm** by the authorized investigation owners.

## Floor-Wide Message

A floor-wide message is **not appropriate at this stage**. Only one individual is currently confirmed affected, and the security/data-governance investigation is incomplete. A broad message could imply a confirmed wider exposure, disclose matter-related information, or cause unnecessary concern before the access path and scope are known.

Reassess communications when Security/Data Governance confirms the scope, affected population, required user action, and approved wording. If more users or matters are confirmed affected, the incident owner should issue targeted or floor-wide communication through the approved legal/privacy and security process.
