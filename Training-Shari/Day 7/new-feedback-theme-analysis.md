# New Feedback Theme Analysis

## 1. Shared credentials vault inaccessible
**Comments:** 5, 8, 14  
**Impact:** Blocker  
**Summary:** The shared credentials vault is unavailable to multiple users and is blocking the whole team. The issue has continued for at least three days and has been escalated to management.

**Evidence:**
- “Shared credentials vault is completely inaccessible, whole team blocked.”
- “Third day now I can't access the credentials vault, this is urgent.”
- “Vault access still broken, escalated to my manager now.”

## 2. Test VM remote access unavailable
**Comments:** 1, 12  
**Impact:** Blocker  
**Summary:** Engineers cannot connect to their test virtual machines after the update, preventing them from doing their work.

**Evidence:**
- “Can't remote into any of my test VMs since the update, blocking my whole day.”
- “My test VM access is still down, can't do my job today either.”

## 3. Admin console lockouts
**Comments:** 3, 10  
**Impact:** Blocker  
**Summary:** Access to the admin console is failing for more than one engineer and is spreading across the team.

**Evidence:**
- “Second engineer this week locked out of the admin console entirely.”
- “Admin console lockouts happening across the whole team now, not just one person.”

## 4. Portal and dashboard appearance changes
**Comments:** 2, 4, 11, 15  
**Impact:** Minor to moderate  
**Summary:** Users noticed changes to colours, dark mode, font size, and icons. Some changes are welcomed, while the smaller font creates a readability concern for some users.

**Evidence:**
- “New ticketing system dashboard is a nicer colour scheme, small win.”
- “Font in the new portal is slightly smaller, hard to read for some of us.”
- “Nice that the new theme supports dark mode properly now.”
- “Small UI icon changes, took a second to adjust but fine.”

## 5. Notification sound changes
**Comments:** 7  
**Impact:** Minor  
**Summary:** Notification sounds changed and are mildly irritating, but the change is not preventing users from working.

## 6. Slower dashboard refresh
**Comments:** 9  
**Impact:** Minor  
**Summary:** The dashboard refreshes more slowly than before, but the impact is currently barely noticeable.

## 7. Positive rollout experience
**Comments:** 6, 13  
**Impact:** Positive  
**Summary:** Some users described the rollout as smoother than the previous one, while others reported no problems.

## Priority view

The credentials vault, test VM access, and admin console lockouts are the highest-priority themes because they prevent teams or engineers from working. Portal readability should be reviewed next. The notification sound and dashboard refresh changes are lower-impact usability concerns. Overall feedback also includes positive comments about the rollout.
